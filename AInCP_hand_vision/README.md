# AInCP – Computer Vision Project

This folder contains computer vision research developed within
the AInCP project at Scuola Superiore Sant’Anna.

## Scope
- Vision-based hand pose estimation
- Sensor validation and analysis
- Experimental pipelines and evaluation

## Data & Privacy
Raw experimental data (human subjects, videos, motion capture)
are not included due to ethical and privacy constraints.

## Status
Ongoing research project
